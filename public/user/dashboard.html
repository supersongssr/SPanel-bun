v2rayN 经典好用

经典且强大的 Windows 代理客户端，完美支持 V2Ray / Xray / Trojan / Shadowsocks 等所有主流混淆协议。

官方内置渠道极速下载 (.zip)

1. 下载并完整解压软件包，双击文件夹内的 v2rayN.exe 运行。

2. 在上方菜单点击 订阅分组 -> 订阅分组设置 -> 点击 添加。

3. 别名随意填写，地址粘贴复制好的通用订阅链接，勾选 启用订阅 并保存。

4. 返回主界面，点击 订阅分组 -> 更新当前订阅(不通过代理) 获取节点列表。

5. 选中节点右键 设为活动服务器，并在底部状态栏将 系统代理 设为 自动配置系统代理 即可。

v2rayNG 极简高效

安卓端使用最为广泛的客户端，界面简单直观，适配多种复杂的底层数据混淆传输方式。

官方内置渠道极速下载 (.apk)

1. 下载并安装 APK 客户端文件，打开 v2rayNG。

2. 点击左上角三横菜单 -> 进入 订阅设置 -> 点击右上角 + 添加。

3. 备注名随意写，地址粘贴复制好的订阅链接，保存并返回主界面。

4. 点击右上角三个点菜单 -> 更新订阅 获取物理节点列表。

5. 任意点击选中一台合适的节点服务器，点击右下角圆形的 V 启动图标即可开启代理。

开源核心，免费无广告，轻量省电。可以在非中国区 App Store 免费搜索并安装。

前往 App Store 下载 Sing-Box-VT

1. 点击上方一键导入或在下方复制 singbox 订阅链接。

2. 运行 v2rayN 应用，并添加复制的通用订阅链接至订阅分组中。

3. 更新当前订阅，选中物理加速节点并开启系统代理即可畅享高速体验。

v2rayA Linux 极客必选

一款非常强悍的 Linux 底层网卡代理管理器。支持开机全局透明代理。使用网页控制台，适配所有发行版。

前往 v2rayA 官方多架构发行版安装手册

1. 部署完成后，在终端启动服务：sudo systemctl start v2raya.service。

2. 在浏览器内访问：http://127.0.0.1:2017（首次打开需设置管理账号密码）。

3. 点击 导入/Import 按钮，将通用订阅链接粘贴进去并保存更新。

4. 勾选或进入物理服务器节点列表，选择目标加速服务器点击 启动/Start 代理。

OpenWrt ShadowsocksR Plus+ / OpenClash 智能路由器推荐

在软路由或路由器上订阅并连接加速节点，瞬间使局域网内所有连网设备（如电视机、游戏机、智能家居）均具备高速物理代理分流能力。

1. 进入您的 OpenWrt 路由器管理 LuCI 界面。

2. 找到 服务 -> ShadowsocksR Plus+（或 OpenClash / v2rayA）菜单项。

3. 导航到 订阅管理，粘贴通用订阅地址，点击保存并立即进行节点强制更新。

4. 节点载入完毕后，在 主服务器 选项框内选择一台延迟较低的物理加速服务器节点。

5. 设置代理模式为 绕过大陆 IP，点击 保存并应用 按钮使路由器即刻接管全网分流。
